# 求职申请管理看板 - 前后端一体版

该版本在原有 MVP 基础上，完成了你提出的 4 个后续需求：

1. 新增 Offer 对比决策页（按薪资、成长性、匹配度、稳定性综合打分）
2. 新增周报自动生成功能（支持一键复制）
3. 新增后端 API + SQLite 数据库（前端自动检测并切换数据模式）
4. 新增账号登录与多用户数据隔离（每个账号仅可访问自己的申请数据）

## 功能清单

- 看板视图：流程拖拽流转（待投递 -> Offer -> 已结束）
- 日历视图：截止日期聚合展示
- 列表视图：筛选、编辑、删除、快速改状态
- Offer 对比：自动计算综合分并排序
- 周报生成：自动汇总本周进展、风险、下周重点，支持复制与导出 TXT
- 风险提醒：14/7/3/1天 + 逾期事项
- 数据面板：申请总数、面试率、Offer率
- 账号体系：登录/注册一体化、会话令牌、用户数据隔离

## 项目结构

- `index.html`：页面结构
- `styles.css`：样式与响应式布局
- `app.js`：前端状态管理、渲染与 API 调用
- `server.js`：Express 服务与 SQLite 接口
- `package.json`：依赖和启动脚本
- `.gitignore`：忽略 node_modules 与数据库文件
- `求职申请管理看板_产品方案.md`：产品设计文档

## 启动方式（推荐）

1. 安装依赖
	- `npm install`
2. 启动服务
	- `npm start`
3. 浏览器访问
	- `http://localhost:3000`

页面顶部会显示当前模式：
- `后端API + SQLite`：已连接数据库
- `本地存储`：后端未启动时自动降级

## 第4步使用方式

1. 启动后端服务后，在页面顶部输入用户名和密码。
2. 点击“登录/注册”：
	- 若用户不存在，则自动注册并登录。
	- 若用户已存在，则按密码登录。
3. 登录后仅能看到当前账号的申请数据。
4. 切换账号后将看到另一份独立数据集。

## API 概览

- `GET /api/health`：健康检查
- `POST /api/auth/register-login`：注册/登录
- `GET /api/auth/me`：获取当前登录用户
- `POST /api/auth/logout`：退出登录
- `GET /api/applications`：查询申请列表
- `POST /api/applications`：新增申请
- `PUT /api/applications/:id`：更新申请
- `DELETE /api/applications/:id`：删除申请
- `POST /api/seed`：重置示例数据
